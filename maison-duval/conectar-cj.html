Conectar CJdropshipping

Esta página convierte tu API Key de CJ en un Access Token. Lo hace directamente entre tu navegador y la API oficial de CJ (developers.cjdropshipping.com). La clave no se guarda ni se envía a ningún otro sitio.

  1. En CJ, abre Mi cuenta → Authorization → API (cjdropshipping.com/my.html#/authorize/API). Pulsa Add API, elige el tipo API Key y copia la clave.
  2. Pégala aquí debajo y pulsa «Obtener token».
  3. Copia el token y pégalo en el formulario seguro que te muestra Claude, nunca en el chat.

Cuando termines, cierra esta página. Si algún día quieres cortar el acceso, borra esa API en CJ (Authorization → API) y el token dejará de funcionar.
